# Mi Mini Pokédex

Sitio estático sencillo con búsqueda, filtro por tipo y favoritos guardados en el navegador. Contiene datos de ejemplo y emojis ilustrativos, no imágenes oficiales.

## Publicación en GitHub Pages
1. Sube `index.html` a la raíz de un repositorio público.
2. Ve a **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Abre la URL que GitHub Pages genere.

Funciona sin API ni instalación. Proyecto de aficionados no afiliado a Pokémon / Nintendo / Game Freak.
